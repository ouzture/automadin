# Security policy

## Supported versions

Security fixes are provided for the latest released version of Automadin.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include private user
data in a report. Use the repository's **Security** tab and select
**Report a vulnerability** to submit a private GitHub security advisory.

Include the affected version, the security impact, reproduction steps, and a
minimal proof of concept when it is safe to do so. Use synthetic data and remove
credentials, tokens, browser profiles, databases, logs, and personal paths.

If private vulnerability reporting is not available for the repository, open a
public issue containing no vulnerability details and ask the maintainer to enable
a private reporting channel.
