# Automadin

Build repeatable automation for websites, Android devices, and Windows
applications without turning every task into a programming project.

Automadin combines a visual flow editor with target-aware commands, reusable
values, visual recognition, scheduling, and detailed run feedback. You keep the
flow: Automadin handles connecting to the selected target and executing each
step in order.

## Choose where to begin

- **Ready to operate flows:** Use [saved run setups and schedules](user-guide/run-setups-and-schedules.md).

- **Contributing:** Start with the [project overview](project-overview.md).

## Capabilities at a glance

| Area | Examples |
| --- | --- |
| Browser | Navigate, locate and click elements, fill forms, manage tabs, extract text, assert page state |
| Android | Tap, swipe, type, press keys, install or launch apps, open activities and deep links |
| Windows | Reacquire or launch an application, click, drag, type, scroll, use image-relative actions |
| Visual automation | Capture screenshots, match template images, find dynamic targets, read text and numbers |
| Flow logic | Conditions, loops, switch/case, subflows, inputs, variables, outputs, hooks, error policies |
| Operations | Saved run setups, input overrides, schedules, history, notifications, backups and diagnostics |

Automadin is a Windows x64 desktop application. Features that depend on browsers,
ADB, OCR, or notifications require their corresponding runtime or account setup.
The in-app **Setup center** is the authoritative readiness check for the current
computer.

!!! note "Documentation scope"

    The user guide describes the current release and uses synthetic example data.
    Architecture, persistence, and build documents are maintained separately for
